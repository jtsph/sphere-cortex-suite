# Sphere Cortex Dev Suite

Sustainable software development suite for thesphere.online / cortex.thesphere.online.

## Features
- Vercel deployment
- Placeholders for ChatGPT, MetaMask, multi-rail payments (Lloyds, Revolut, Apple Pay, Visa, Mastercard, direct debits, BNB)

## Deploy
Connected to Vercel. Push to main for auto-deploy.

## Note
Full financial integrations require proper compliance, API credentials, and legal setup. This is a starter.
